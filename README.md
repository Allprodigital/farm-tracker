# Farm Tracker

Farm Tracker by All Pro Digital, a Valley Pro Logistics LLC company. Milestone 1 demo: fields, current operation, next to do, notes, spray and harvest records, status history. Phone-first PWA; data stays on the phone (localStorage).

See [PLAN.md](PLAN.md) for scope and data model. Static site: open `index.html` or serve the folder. Icons: `python3 tools/make_icon.py && node tools/render_icons.js`. Test: `node tools/test.js <url> [shotsDir]`.
